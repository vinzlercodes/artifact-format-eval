# Format Decision Tree

Use this as the practical decision layer for the HTML-versus-Markdown tradeoff measured by the
benchmark.

Use Markdown when source review and lightweight editing are primary.

Use static HTML when presentation and comprehension matter more than direct source editing.

Use HTML+SVG when the structure is visual and a linear document hides relationships.

Use interactive HTML when filtering, sorting, tabs, or drill-down changes task success.

Use JSON+renderer when validation, repeatable rendering, or agent handoff matters.

Use notebook output when executable analysis and cell-level context are part of the artifact.
