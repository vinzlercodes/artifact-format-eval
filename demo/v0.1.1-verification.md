# v0.1.1 Verification

## Local Setup

Install browser binaries before running the Playwright gate locally:

```bash
pnpm exec playwright install chromium
```

CI uses:

```bash
pnpm exec playwright install --with-deps chromium
```

## Verification Commands

```bash
pnpm format:check
pnpm validate
pnpm typecheck
pnpm test
uv run pytest
pnpm benchmark
uv run python -m artifact_eval_notebook validate results/prior-auth/baseline/artifact.ipynb
pnpm doctor --ci
pnpm test:playwright
pnpm verify
```

## Expected Outputs

- `pnpm format:check` reports all checked files use Prettier formatting.
- `pnpm benchmark` writes template and agent-corpus outputs under ignored `results/` and refreshes ignored `site-dist/`.
- `pnpm test:playwright` loads prior-auth HTML artifacts from `file://`, detects no baseline external network requests, verifies the interactive included filter, and checks the generated accessibility mutation evidence.
- `pnpm verify` completes without requiring API keys.
